NOVA-HDL-Assist

A RAG assistant inside a web-based VHDL template editor, so engineers can ask questions and configure modules in plain language.

  • The goalGive an existing VHDL template editor an assistant that answers from the project's own documentation, not from guesses.
  • The stackPython and Flask for the backend, ChromaDB as the vector store, open-weight LLMs for answer generation.
  • Grounded answersA hybrid policy uses the retrieved context first and only falls back on general model knowledge when retrieval is thin.
  • Integrated, not bolted onThe assistant lives inside the editor, next to the templates engineers are already configuring.
  • Two-phase retrievalSection-level routing first, then chunk-level search, so the model only sees context from the part of the docs that matters.
  • Two-collection vector storeSeparate ChromaDB collections for sections and chunks.
  • Asymmetric embeddingsQueries and documents are embedded differently, matching short questions to longer technical passages.
  • Structure-aware chunkingChunks follow the document's own structure instead of a fixed sliding window.
  • LLM-as-judgeAn evaluation workflow where a model scores answers, used to compare configurations consistently.
  • Hyperparameter calibrationRetrieval settings were tuned against that evaluation rather than picked by hand.
  • Chunking resultStructure-aware chunking outperformed naive sliding-window chunking.
