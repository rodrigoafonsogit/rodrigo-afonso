Selected work

NOVA-HDL-Assist

Master's dissertation. A RAG assistant inside a web-based VHDL template editor, so engineers can ask questions and configure modules in plain language.

PythonFlaskChromaDBEmbeddingsOpen-weight LLMsLLM-as-judge
  • Two-phase retrievalSection-level routing first, then chunk-level search, so the model only sees context from the part of the docs that matters.
  • Two-collection vector storeChromaDB with separate section and chunk collections, and asymmetric embeddings for queries and documents.
  • Structure-aware chunkingChunks follow the document's own structure. It outperformed naive sliding-window chunking.
  • Measured, not guessedHyperparameters calibrated with an LLM-as-judge evaluation workflow, plus a hybrid policy that falls back on general model knowledge when retrieval is thin.
